# SusiAir Test for Full Stack Developer by Bagus Seno Pamungkas

## Description

SusiAir Test for Full Stack Developer by Bagus Seno Pamungkas. Backend side.

## Project setup

```bash
$ pnpm install
```

## Compile and run the project

```bash
# development
$ pnpm run start

# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

This will run on port 3001 by default. To change port, create an .env file and set
PORT=Your preferred port
